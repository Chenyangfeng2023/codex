# V1 文件使用说明

- Markdown：完整研究方案与引用。
- HTML：下载后用浏览器打开，顶部点击「导出 PPT」即可离线下载对应 V1 的可编辑 PPTX；无须第三方转换服务。
- PPTX：35 页、16:9；正文、表格和链接保留为原生可编辑元素。

HTML 内嵌的是本版本生成的 PPTX 快照。若修改 HTML 或研究正文，需重新生成并同步内嵌文件；导出按钮不会转换手工修改后的 DOM。

字体优先 Noto Sans CJK SC／Noto Serif CJK SC；PowerPoint 所在系统未安装时会替换字体，换行可能略有差异。配色与画幅沿用原 HTML，网页特有渐变和交互不作为 PPT 动画。

HTML 支持方向键翻页、目录跳转、总览与打印。GitHub 文件页展示源码，需下载 HTML 后在浏览器打开使用按钮。
